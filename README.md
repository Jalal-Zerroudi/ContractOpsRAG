# ContractOpsRAG
ContractOps-RAG FR est un copilote contractuel pour contrats français : Q/R avec citations (RAG), comparaison de versions et redlining des clauses. Stack : ASP.NET Core + FastAPI, PostgreSQL/pgvector. Sécurité OAuth2/OIDC, Docker &amp; GitHub Actions. Azure (ACR, Container Apps/AKS). OpenTelemetry + Azure Monitor.
